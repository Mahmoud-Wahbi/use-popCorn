# 🍿 usePopcorn

A movie search and watchlist application built with React. Search for movies, explore their details, rate them, and track your watched movies with personalized statistics.

## ✨ Features

- Search for movies using the OMDb API.
- View movie details and ratings.
- Rate movies from 1 to 10 stars.
- Add and remove movies from your watched list.
- Track viewing statistics, including average ratings and runtime.
- Save your watched list using `localStorage`.
- Use keyboard shortcuts for easier navigation.

## 🛠️ Built With

- React 19
- JavaScript (ES6+)
- React Hooks and Custom Hooks
- OMDb API and Fetch API
- CSS3
- Browser `localStorage`
- Create React App

## 💡 What I Learned

This project helped me deepen my understanding of React's `useEffect` hook through extensive practical use. I gained a clearer understanding of when and why to use effects, how dependency arrays influence their execution, and how effects interact with component rendering.

I also learned to recognize the benefits and drawbacks of `useEffect`, including handling side effects, avoiding unnecessary executions, and managing effect cleanup when needed. This experience helped me write more thoughtful and predictable React code.
